# caffeinate

`caffeinate` は、Mac が操作されていない間に自動でスリープするのを一時的に抑えるコマンドです。ダウンロード、バックアップ、長時間かかる処理などの途中で Mac がスリープするのを避けたいときに使います。

> **対象 OS:** macOS 専用のコマンドです。Linux で同じ名前やオプションが使えるとは限りません。このページのコマンドは macOS で実行してください。

## 基本構文

```bash
caffeinate [オプション] [-t 秒数]
caffeinate [オプション] [-t 秒数] コマンド [引数...]
```

コマンドを続けて指定しない場合は、`caffeinate` 自身がスリープ抑止の要求を保持します。コマンドを指定した場合は、そのコマンドが動いている間だけ要求を保持します。

主に使うオプションは次のとおりです。

| オプション | 内容 |
| --- | --- |
| `-i` | 操作がないときに Mac 本体が自動でスリープするのを抑止する |
| `-d` | ディスプレイがスリープするのを抑止する |
| `-t 秒数` | 指定した秒数だけスリープ抑止の要求を保持する |
| `-s` | Mac 本体のスリープを抑止する。AC 電源に接続している場合に限り有効 |

## Mac 本体の自動スリープを抑止する

`-i` を付けて実行します。

```bash
caffeinate -i
```

このコマンドは、ターミナルで実行している間、操作がなくても Mac 本体が自動でスリープするのを抑止します。コマンドを実行したターミナルは開いたままにしてください。

`-i` は Mac 本体のアイドル時のスリープを抑止しますが、ディスプレイの消灯までは止めません。画面が消えても、Mac 本体は動作を続けることがあります。

## ディスプレイも点灯したままにする

`-d` はディスプレイのスリープを抑止します。Mac 本体のアイドル時のスリープもあわせて抑止するには、`-d` と `-i` を組み合わせます。

```bash
caffeinate -d   # ディスプレイのスリープを抑止
caffeinate -di  # ディスプレイと Mac 本体のアイドル時スリープを抑止
```

## 時間を指定して実行する

`-t` の後ろに秒数を指定すると、その時間が過ぎたときにスリープ抑止の要求が解除されます。たとえば、8 時間は 28,800 秒です。

```bash
caffeinate -i -t 28800
```

コマンド自体を指定する形式では、`-t` による時間指定は無視されます。その場合、スリープ抑止は指定したコマンドが終了したときに解除されます。

## 実行を終了する

時間を指定せずに実行した `caffeinate` を確実に終了するには、実行中のターミナルで `Control + C` を押します。ターミナルを閉じたときの挙動は、使用しているターミナルやシェルによって異なることがあります。

## 注意点

- `-i` が抑止するのは操作がないときの自動スリープです。Apple メニューから手動でスリープした場合や、MacBook の蓋を閉じた場合にも動作が続くとは限りません。
- 再起動すると実行中の `caffeinate` は終了します。再起動後もスリープを抑止したい場合は、再起動後にあらためて実行してください。
- `-s` は AC 電源に接続している場合に限り有効です。バッテリー駆動中に使うオプションではありません。
- スリープを抑止すると消費電力が増えることがあります。MacBook で長時間使う場合は、電源アダプタに接続してください。
- `caffeinate` はスリープ抑止の要求を保持するためのコマンドで、通常はそれ自体の処理負荷は小さいものです。ブラウザなど実行中のアプリが使うメモリーを減らす機能はありません。

## システム設定から変更する

コマンドを使わず、システム設定から自動スリープを調整することもできます。項目名や表示場所は Mac の機種や macOS のバージョンによって異なる場合があります。

- MacBook の場合は、Apple メニューから「システム設定」>「バッテリー」>「オプション」を開き、「ディスプレイがオフのときに電源アダプタ接続時の自動スリープを防ぐ」を設定します。この項目は電源アダプタに接続している場合に適用されます。
- デスクトップ Mac の場合は、「システム設定」>「エネルギー」を開き、「ディスプレイがオフのときに自動スリープを防ぐ」を設定します。
- 画面の消灯時間は、「システム設定」>「ロック画面」で、バッテリー駆動時または電源アダプタ接続時に操作がないとき、ディスプレイを消灯するまでの時間を設定します。この設定は画面の消灯時間を調整するもので、Mac 本体の自動スリープを抑止する設定とは別です。
