# sort コマンド

```bash
sort オプション 入力ファイル
```

デフォルトでは行全体を文字コード順(ロケール依存)で昇順に並べ替えて標準出力に出す。元のファイルは変更されない。

## オプション

`-r` : 降順にする
`-n` : 数値として比較する(`10` が `2` より後に来る)
`-h` : `1K`, `2M`, `3G` のような人間向けサイズ表記を比較する(`du -h` の出力など)
`-u` : 重複行を除去する
`-f` : 大文字小文字を区別しない
`-k N` : N 番目のフィールドをキーにする。`-k 2,2` で 2 列目だけ、`-k 2` だと 2 列目から行末までが対象になる
`-t 区切り` : フィールド区切り文字を指定する(デフォルトは空白)
`-o file` : 結果を file に書き出す(入力と同じファイルでも安全)
`-V` : バージョン番号順に並べる(`1.2` < `1.10`)

## ユースケース

```bash
sort file                  # 昇順に並べ替える
sort -r file               # 降順に並べ替える
sort -n file               # 数値の昇順に並べ替える
sort -t, -k2,2n file.csv   # CSV の 2 列目を数値として昇順に並べ替える
sort -u file               # 並べ替えて重複行を除去する
sort file | uniq -c | sort -rn # 行の出現回数を数えて多い順に並べる
sort file -o file          # file 自体を並べ替えて上書きする
```

## 注意点

- `sort file > file` は redirect が先に file を空にしてしまうので内容が消える。上書きしたいときは `-o` を使う。
- 文字コード順で比較したいときは `LC_ALL=C sort file` とする。ロケールによって日本語や大文字小文字の順序が変わるので、環境差を無くしたいときにも有効。
- 数値を `-n` なしで並べると `1, 10, 2` のように文字列順になる。
- ヘッダー行を残して並べ替えたいときは `(head -n1 file; tail -n+2 file | sort) > out` とする。
