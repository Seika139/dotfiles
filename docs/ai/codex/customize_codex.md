# Codex の挙動をカスタマイズする

- <https://learn.chatgpt.com/ja-JP/docs/customization/overview?utm_source=chatgpt.com>

## AGENTS.md

リポジトリ単位で挙動を制御するには AGENTS.md を使用します。
ここではエージェントが作業を開始する前に適用される永続的なプロジェクトガイダンスを定義します。
内容は簡潔に保つことが望ましいです。
リポジトリ単位でのルールはリポジトリのルートに配置された AGENTS.md に記載し、ディレクトリ固有のガイダンスは各ディレクトリに配置された AGENTS.md に記載するのが良いとされています。

ルールの例

- ビルドとテストのコマンド
- レビューで求めること
- リポジトリ固有の規約
- ディレクトリ固有の指示

### AGENTS.md の運用方針

先ずは重要な指示だけを AGENTS.md に記載します。
エージェントがコードベースについて誤った想定をした場合は、AGENTS.md でそれを修正し、その修正が維持されるようエージェントに AGENTS.md の更新を依頼します。これをフィードバックループとして活用してください。

AGENTS.md の更新： まずは重要な指示だけを記載します。繰り返されるレビュー指摘をルールとして明文化し、ガイダンスは適用先に最も近いディレクトリに配置します。また、何かを修正したときはエージェントに AGENTS.md の更新を指示し、以後のセッションにも修正が引き継がれるようにします。

### AGENTS.md の更新タイミング

- 同じミスの繰り返し：エージェントが同じミスを繰り返す場合は、ルールを追加します。
- ドキュメントの読みすぎ：適切なファイルを見つけていてもドキュメントを読みすぎる場合は、ルーティングのガイダンス（優先するディレクトリやファイル）を追加します。
- 繰り返される PR フィードバック：同じフィードバックを複数回残す場合は、ルールとして明文化します。
- GitHub で：Pull Request のコメントで、リクエストとともに @codex をタグ付けし（例：@codex add this to AGENTS.md）、更新をクラウドチャットに委任します。
- ドリフトチェックの自動化：スケジュール済みタスクを使用して、ガイダンスの抜けを探し、AGENTS.md に追加すべき内容を提案する定期チェック（例：毎日）を実行します。

## CI/CD の有効活用

pre-commit フック、リンター、型チェッカーなどを積極的に利用しましょう。
これらのツールは非決定的な出力をする AI よりもコード品質の担保がしやすいため、AI に委ねる前にこれらのツールの設定をすることで、それ以外の観点に AI を集中させることができます。

たとえば `AGENTS.md` に

```text
- gofmt が通っているか
- unused import がないか
```

のような記載がある場合は修正が必要です。CIなどのコードベースでルールが守られるように設定します。
